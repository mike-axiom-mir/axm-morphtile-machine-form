# Roadmap

1. Keep every compatibility claim tied to exact runtime evidence; never infer future MorphTile compatibility from source inspection alone.
2. Land bounded composition rules only when they replace a repeated creation pattern with smaller deterministic machinery.
3. Verify the bounded grid lane against the exact pinned MorphTile runtime before integration; retain its 2..64 total-cell budget and fail-closed duplicate protection.
4. Add negative/budget fixtures discovered by real use and keep unsupported requests explicit.
5. Consider conditions, richer parameter expressions, radial layouts or other composition operators only when a repeated grounded creation need justifies one bounded rule at a time.
6. Keep arbitrary recipe-language synthesis, aesthetic judgment and autonomous geometry invention outside the machine until separate evidence supports those lanes.

Do not add speculative breadth merely to make the repository look complete.
