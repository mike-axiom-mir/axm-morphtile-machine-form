# MorphTile Form Machine

Turns bounded form intent into candidate MorphTile mesh matter. The foundation proves a box and caller-supplied recipe mapping.

## Boundary answers

1. **What it does:** Turns bounded form intent into candidate MorphTile mesh matter. The foundation proves a box and caller-supplied recipe mapping.
2. **What it does not own:** Canonical worlds, merge authority, surface quality, behavior, UI, or aesthetic acceptance.
3. **What it accepts:** axm.morphtile.form-request/v0.1 in the provisional v0.1 envelope.
4. **What it produces:** A morphtile.tile-spec/v0.4 candidate; never an automatic world mutation.
5. **MorphTile interaction:** output goes through MorphTile's public contracts and clone → plan → commit → receipt → rollback path. MorphTile does not depend on this repository.
6. **Evidence:** Structural mapping evidence. Visual quality is explicitly not verified.
7. **When it cannot satisfy a request:** Unsupported named forms return HOLD_FORM_VOCABULARY_MISSING.

## Run

    npm test

Node 18 or later; zero runtime dependencies; no secrets or network required.

## Truth boundary

- IMPLEMENTED: the tiny adapter and local envelope used by the fixtures.
- TESTED: the claims named by the local test files.
- EXPERIMENTAL: envelope v0.1 and every candidate schema in this foundation.
- NOT TESTED: compatibility beyond MorphTile commit 13d83a2b2c0d12644442d3d9e45bcbe0af19876a.
- HELD: No arbitrary geometry generation, runtime MorphTile execution, or visual proof.

This is a foundation, not evidence that MorphTile can autonomously manufacture MorphTile.
